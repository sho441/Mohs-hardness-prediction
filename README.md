# Mohs-hardness-prediction
Kaggle Playground（Regression with a Mohs Hardness Dataset）を用いたモース硬度予測モデルの構築・機械学習ポートフォリオ。

## 1.プロジェクトの概要
鉱物の組成や物理的特性データをもとに、鉱物の「モース硬度」を高精度に予測する回帰モデルを構築。
予測手法として勾配ブースティングモデル（LightGBM）を採用し、Optunaによるハイパーパラメータチューニングを実施しました。
予測精度の追求だけでなく、どのような化学組成や物性特徴量が硬度に強く影響しているかを分析し、材料科学的な解釈やインサイトを導出しました。

## 2.ビジネス・研究的な背景
新素材の開発や材料選定の現場において、物質の硬度（耐摩耗性や加工難易度）を迅速かつ高精度に予測することは、実験コストの削減や開発リードタイムの短縮において極めて重要です。
本プロジェクトでは、実務を想定した厳格な検証環境下で、機械学習を用いた物性値予測の有効性を検証しました。

## 3.使用した技術・ライブラリ
* **言語**: Python 3.x

* **データ処理・分析**: Pandas, NumPy, Scikit-learn

* **機械学習モデル**: LightGBM, XGBoost, CatBoost, RandomForest, Ridge / Lasso 他

* **ハイパーパラメータ最適化**: Optuna

* **検証手法**: 交差検証 (Cross-Validation, 5-Fold)

## 5.アプローチと工夫点
### ① 厳格な検証設計

&emsp; ・データリークを防ぎ、未知のデータに対する真の汎用性能を正しく評価するため、ネステッド交差検証を採用。

### ② ドメイン知識に基づく高度な特徴量エンジニアリング

・鉱物の化学組成比率や物性値間の相互作用に着目し、非線形な関係性を捉えるための派生特徴量や統計量を多角的に生成。

### ③ 複数モデルの比較と重み付きアンサンブル

・13種類のアルゴリズム（勾配ブースティング系、線形モデル等）を比較・検証。

・Optunaによるハイパーパラメータチューニングを実施し、汎化性能の最大化を追求。

## 6.結果と考察
### ・予測精度

・ローカルでのクロスバリデーションスコア（CV RMSE / Score: 0.64039）に対し、未知データに対するパブリックスコア（Public Score: 0.61435）においても同等水準の精度を維持。

・過学習を効果的に抑制し、コンペティション環境特有のノイズに過度に適合しない、堅牢な汎用性能を確認。

### ・特徴量重要度（解約要因のインサイト）の分析

・特徴量重要度の分析から、モース硬度に寄与する主要な物性・組成特徴量を特定。

・得られたモデルの挙動が、材料科学的な傾向やドメイン知識と矛盾していないかを定性的に検証し、ブラックボックスになりがちな予測モデルの解釈性を担保。
