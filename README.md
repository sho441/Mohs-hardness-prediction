# Mohs-hardness-prediction
Kaggle Playground（Regression with a Mohs Hardness Dataset）を用いたモース硬度予測モデルの構築・機械学習ポートフォリオ。

## 1.プロジェクトの概要
鉱物の組成や物理的特性データをもとに、鉱物の「モース硬度」を高精度に予測する回帰モデルを構築。
予測手法として複数の機械学習モデルの比較・検証を行い、最終的にアンサンブルモデル（または最適化された勾配ブースティングモデル）を採用しました。
予測精度の追求だけでなく、どのような化学組成や物性特徴量が硬度に強く影響しているかを分析し、材料科学的な解釈やインサイトを導出しました。

## 2.ビジネス・研究的な背景
新素材の開発や材料選定の現場において、物質の硬度（耐摩耗性や加工難易度）を迅速かつ高精度に予測することは、実験コストの削減や開発リードタイムの短縮において極めて重要です。
本プロジェクトでは、実務を想定した厳格な検証環境下で、機械学習を用いた物性値予測の有効性を検証しました。

## 3.使用した技術・ライブラリ
* **言語**: Python (3.0)

* **データ処理・分析**: Pandas, NumPy, Scikit-learn

* **機械学習モデル**: LightGBM, XGBoost, CatBoost, RandomForest, Ridge / Lasso 他

* **ハイパーパラメータ最適化**: Optuna

* **検証手法**: 交差検証 (Cross-Validation, 5-Fold)

### ② ドメイン知識に基づく高度な特徴量エンジニアリング

・単体モデルおよび最適化された重み付きアンサンブルにより、安定した高い ROC-AUCスコア (5-Fold CV OOF ROC-AUC: 0.91667) を達成。過学習を抑えつつ、実務に耐えうる汎用性を確認。

・最適化されたモデルにより、安定した高い予測精度（CV RMSE等）を達成。過学習を抑えつつ、実務に耐えうる汎用性を確認。

### ・特徴量重要度（解約要因のインサイト）の分析

・特徴量重要度の分析から、どの組成や物理特性がモース硬度の向上・低下に強い影響を与えているかを特定。

・物理的・化学的解釈との整合性を検証し、モデルのブラックボックス性を軽減。
